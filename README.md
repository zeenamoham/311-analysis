# Harlem Lighting, Surveillance, and Perceptions of Safety

This project investigates patterns in lighting infrastructure and public perceptions of safety along the 125th Street corridor in Harlem.

The analysis combines:
- NYC 311 lighting complaint data
- Field-collected light intensity measurements
- Geospatial analysis
- Interactive visualization using Mapbox
